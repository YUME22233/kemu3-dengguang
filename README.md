# 科目三 · 夜间灯光模拟考试

一个**纯前端、单文件、可离线运行**的科目三夜间灯光模拟考试程序。跟随中文语音指令，在限定时间内操作灯光，程序自动判分并生成成绩单。

界面包含夜间道路场景、车内灯光操作台、语音播报字幕、倒计时、状态指示灯（示宽 / 近光 / 远光 / 雾灯 / 双闪）以及题库速查。

![界面预览](docs/preview.png)

## 快速开始

1. 双击 `dist/科目三灯光模拟考试.html`，或双击 `启动考试.cmd`。
2. 建议使用 **Edge / Chrome**，窗口宽度 1100px 以上体验最佳；手机端也已适配。
3. 点击「开始考试」，听到语音指令后操作灯光。

> 语音使用浏览器内置的 Web Speech API。Windows 通常自带中文语音（如 Microsoft Huihui）；Edge 还可能提供在线「晓晓」。没有中文语音时，程序会自动退化为「文字指令 + 提示音」，不影响判分。

## 功能

- **13 项标准题库**：12 个夜间场景 + 「请开启前照灯」，随机抽题，避免连续三题同类型。
- **真实计时**：语音播报结束后开始 5 秒倒计时（可调 3 / 5 / 8 秒），超时判错。
- **自动判分**：根据最终灯光状态、交替次数判定，全部正确才算合格。
- **可视化操作台**：三档旋钮式总开关、近 / 远光、交替拨杆、雾灯、双闪，全部可点击，也可用键盘。
- **实时灯光场景**：近光 / 远光、示宽灯、后雾灯、双闪、雾天薄雾都有对应视觉反馈。
- **语音 + 字幕 + 跳过播报**：可随时跳过开场白，直接开始计时。
- **题库速查 / 考试规则**：13 项标准操作与易错点，支持逐条试听语音。
- **教练提示 / 严格模式**：学习时可显示正确操作；严格模式考试中不公布单题结果。
- **成绩单与错题重练**：逐题回顾「你的操作 / 正确操作 / 提示」，可只练错题。
- **设置记忆**：题量、限时、语音、音效等保存在浏览器 localStorage。

## 操作说明

| 操作 | 界面 | 快捷键 | 说明 |
| --- | --- | --- | --- |
| 灯光总开关 | 旋钮 / 下方三个档位 | `0` `1` `2` | 关闭 → 示宽灯 → 前照灯，循环切换 |
| 近光灯 | 近光按钮 | `Q` | 需先开启前照灯 |
| 远光灯 | 远光按钮 | `W` | 需先开启前照灯 |
| 交替远近光 | 「拉动拨杆」按钮 | `Space` / `E` | 连按两次算完成交替，最终回到近光 |
| 雾灯 | 雾灯按钮 | `F` | 需先开启示宽灯或前照灯 |
| 双闪 | 双闪按钮 | `H` | 危险报警闪光灯，独立开关 |
| 开始考试 | 首页按钮 | `Enter` | 首页按回车可直接开始 |
| 退出考试 | 右上角「退出考试」 | `Esc` | 会弹出确认 |

## 判分规则

每题在**语音播报结束后**开始计时；在时限内达到要求的灯光状态即自动通过，超时或状态不符判错。

| 题型 | 判定条件 |
| --- | --- |
| 开启前照灯 | 总开关处于前照灯档 |
| 远光灯 | 前照灯 + 远光 |
| 近光灯 | 前照灯 + 近光 |
| 交替远近光 | 前照灯 + 交替次数 ≥ 2 + 最终为近光 |
| 雾天行驶 | 雾灯 + 双闪，且不能是远光 |
| 故障 / 临时停车 | 示宽灯 + 双闪 |

- 真实科目三灯光考试中，**任何一项操作错误即判定不合格**，因此本程序也以「全部正确」为合格。
- 分数按正确题数折算（100 分制），用于直观展示；最终判定以是否全对为准。
- 若上一题结束后灯光状态已经满足下一题要求（例如连续两道近光题），会直接判定通过，符合「按灯光状态判分」的逻辑。

## 题库（13 项）

| # | 语音指令 | 正确操作 |
| --- | --- | --- |
| 01 | 请开启前照灯 | 开启前照灯（近光） |
| 02 | 夜间在没有路灯、照明不良的道路上行驶 | 开启远光灯 |
| 03 | 夜间同方向近距离跟车行驶 | 开启近光灯 |
| 04 | 夜间在窄路、窄桥与非机动车会车 | 开启近光灯 |
| 05 | 夜间与机动车会车 | 开启近光灯 |
| 06 | 夜间通过急弯、坡路 | 交替使用远近光灯 |
| 07 | 夜间通过拱桥、人行横道 | 交替使用远近光灯 |
| 08 | 夜间通过没有交通信号灯控制的路口 | 交替使用远近光灯 |
| 09 | 夜间超越前方车辆 | 交替使用远近光灯 |
| 10 | 夜间在照明良好的道路上行驶 | 开启近光灯 |
| 11 | 雾天行驶 | 雾灯 + 危险报警闪光灯 |
| 12 | 夜间在道路上发生故障，妨碍交通又难以移动 | 示宽灯 + 危险报警闪光灯 |
| 13 | 夜间路边临时停车 | 示宽灯 + 危险报警闪光灯 |

> 各地车管所的具体语音措辞、灯光要求可能略有差异，本程序按通用小型汽车（C1/C2）规则设计，仅用于练习。

## 开发

需要 Node.js 18+（仅用于构建与测试，运行程序本身不需要 Node）。

```bash
# 重新构建单文件版本
npm run build

# 运行核心逻辑测试（14 项）
npm test
```

修改题库：编辑 `src/core.js` 中的 `SCENES` 数组（`text` 指令、`type` 题型、`op` 正确操作、`tip` 提示），再执行 `npm run build`。

修改界面：编辑 `src/index.html` / `src/style.css` / `src/app.js` 后重新构建。

## 说明

- 程序完全在本地运行，不联网、不上传数据；仅使用 localStorage 保存设置。
- 语音是否可用取决于操作系统 / 浏览器是否安装了中文语音；不影响文字指令与判分。
- 场景为示意动画，用于反馈灯光状态，并非真实光照模拟。
